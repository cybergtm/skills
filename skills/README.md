# Skills

Each skill lives in its own folder. The folder name matches the `name` in the skill's `SKILL.md`.

| Skill | What it does |
| --- | --- |
| [ai-design-trope-audit](ai-design-trope-audit/SKILL.md) | Decide which AI-generated design habits your brand accepts, record them as brand rules, and audit a website against them with evidence. |

## Adding a skill

1. Copy `_template` to a new folder named in lowercase with hyphens.
2. Fill in `SKILL.md`, including the security section and credits.
3. Add a row to the table above and to the table in the root `README.md`.
4. Follow the checklist in [CONTRIBUTING.md](../CONTRIBUTING.md).

## Installing a skill

Zip the skill's folder (for example `ai-design-trope-audit`) and upload it as a custom skill in your Claude settings. Availability depends on your plan and organization settings.
