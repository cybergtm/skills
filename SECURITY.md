# Security

These skills load content from the open web and can run short scripts, so security reports are welcome.

To report a problem (for example a way a skill could be tricked into an unsafe action, or a script weakness), use GitHub's private vulnerability reporting under the Security tab of this repository. Please do not open a public issue with exploit details.

Include which skill is affected, what you observed, and how to reproduce it. We will acknowledge reports as soon as we can and credit reporters who want it.
